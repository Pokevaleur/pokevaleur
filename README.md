# PokéValeur

Première version publique d'un outil de suivi de collection.

## Fonctions V1
- inscription et connexion
- collection privée par utilisateur
- ajout d'un produit
- prix et date d'achat
- lieu d'achat
- quantité
- valeur actuelle
- total investi et évolution

## Déploiement
Compatible Vercel avec Supabase.

Déploiement production déclenché depuis la branche main.

PokéValeur est un service indépendant, non affilié à The Pokémon Company, Nintendo, Creatures ou GAME FREAK.
